Config#

Warning

These configs are display only. Finalised configuration files coming soon.

The Config file encodes which pipeline steps are run, and how they are run.

spikesorted provides default configs that can be used directly or tailored to your recording setup and experimental design.

For full details on the required config structure, see the Config Specification page.

To generate your own configs, create a new YAML file from scratch, or generate, save and edit a configuration file below. spikesorted functions accept either the name of a default config name or path to a custom configuration file.

Select a configuration#

You can generate and download an example config file below for inspection. Alterantively, these settings can be used in spikesorted by using the default keyword arguments as suggested after generation.

IBL is only available for Neuropixels.

Generated config

For Neuropixels probes, phase_shift is applied during preprocessing to correct ADC multilexing artefacts.

The IBL approach uses the IBL preprocessing steps, including:

  • Saturation detection and removal

  • High-pass spatial filtering

  • Bad channel interpolation

This config is available by default in spikesorted as .

For example, to use it with the command-line interface, try:

raw_data_quality_metrics:
  chunk_size_s: 1.0
  num_chunks: 30
  rolling_rms_window_size_s: 3.0
  quick_metrics_only: false

bad_channel_detection:
  method: 'coherence+psd'

preprocessing:
  remove_bad_channels: {}  # Remove (not interpolate) bad channels
  phase_shift: {}
  bandpass_filter:
    freq_min: 300.0
    freq_max: 6000.0
  common_reference:
    reference: global
    operator: median

sorting:
  sorter: kilosort4
  params:
    do_CAR: false
    highpass_cutoff: 0.1  # Filtering cannot be entirely disabled in Kilosort

postprocessing:

    max_spikes_per_unit: 2500
  waveforms:
    ms_before: 1.0
    ms_after: 2.0
  templates: {}
  quality_metrics:
    metric_names: all
  compute_sparsity:
    method: radius
