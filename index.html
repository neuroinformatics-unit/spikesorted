spikesorted#

spikesorted is a configurable extracellular electrophysiology pipeline built on SpikeInterface.

spikesorted \
    --sessions /rawdata/sub-001/ses-001 \
    --output_path /my_awesome_project/sub-001 \
    --config /my_awesome_project/pipeline_config.yaml \
    --slurm

Pipeline overview#

Apply a modern extracellular electrophysiology pipeline to your recordings, with options to tailor each step to your data.

See the Roadmap for additional planned steps and features.

Assess quality#

spikesorted saves quality metrics and plots to help you quickly assess the quality of each recording.

Sorting outputs native SpikeInterface objects that can be opened in spikeinterface-gui for manual curation.

Encode and share#

Define your pipeline in a YAML configuration file, improviding reproducability and facilatating analysis sharing.

spikesorted comes pre-loaded with popular default cofigurations. See the Configs page for details, including how to generate your own.

np-standard-kilosort4.yaml
raw_data_quality_metrics:
  chunk_size_s: 1.0
  num_chunks: 30
  rolling_rms_window_size_s: 3.0
  quick_metrics_only: false

bad_channel_detection:
  method: 'coherence+psd'

preprocessing:
  remove_bad_channels: {}  # detected bad channels are removed, not interpolated
  phase_shift: {}  # Neuropixels only
  bandpass_filter:
    freq_min: 300.0
    freq_max: 6000.0
  common_reference:
    reference: global
    operator: median

sorting:
  sorter: kilosort4
  params:
    do_CAR: false
    highpass_cutoff: 0.1  # Low cutoff; Kilosort still applies a high-pass filter

postprocessing:
  random_spikes:
    max_spikes_per_unit: 2500
  waveforms:
    ms_before: 1.0
    ms_after: 2.0
  templates: {}
  quality_metrics:
    metric_names: all
  compute_sparsity:
    method: radius
    radius_um: 100

Standardised outputs#

Pipeline outputs are saved in a predefined, standardised folder structure. This streamlines navigating data and facilitates data sharing, supporting the development of common analysis tools.

The outputs are fully specified, so you know exactly what to expect from each pipeline step. See the Specification for details on each step and the standardised output structure.

Flexible data loading#

Use SpikeInterface to load and prepare recordings before passing them to spikesorted. This is useful for attaching a custom probe layout or concatenating multiple runs into a session.

This example runs bad-channel detection using your own YAML configuration.

import spikeinterface as si
import probeinterface as pi
from spikesorted import Pipeline

run_1 = si.load("/data/saved_recordings/run_1")
run_2 = si.load("/data/saved_recordings/run_2")

session_1 = si.concatenate_recordings([run_1, run_2])

probe_group = pi.read_prb("my-custom-probe-layout.prb")
session_1.set_probe(probe_group.probes[0])

Pipeline(
    recordings=session_1,
    config_path="my_pipeline.yaml",
    output_path="/results/subject_01",
    stop_after_step="bad_channel_detection",
).run()

Try spikesorted#

Running a standard pipeline on an existing recording session is as simple as installing:

pip install spikesorted

and running spikesorted through the command line, pointing it to paths for your session:

spikesorted \
    --sessions /rawdata/sub-001/ses-001/imec0 \
    --output_path /my_awesome_project/sub-001 \
    --config np-standard-kilosort4

You can also run spikesorted through the Python API.
