class spikesorted.steps.bad_channel_detection.BadChannelDetectionStep(
recordings,
config_path,
output_path,
overwrite=False,
num_cores=1,
)[source]#

Detect bad channels for each recording session and shank.

The run() method wraps SpikeInterface’s detect_bad_channels().

Parameters:

  • recordings (RecordingInput | list[RecordingInput]) – A recording, a dictionary mapping shank IDs to recordings, or a tuple of (recording or shank dictionary, session name). Supply a list of these objects to process multiple sessions.

  • config_path (str | Path) – Path to the YAML pipeline configuration file containing the bad_channel_detection settings.

  • output_path (str | Path) – Root output directory under which the step saves outputs for each session and shank.

  • overwrite (bool) – Whether to overwrite existing output CSV files. Default is False.

  • num_cores (int) – Number of CPU cores allocated to the step. Default is 1.

See also

BasePipelineStep, spikeinterface.preprocessing.detect_bad_channels

Notes

The following CSV files are saved for each session and shank:

bad_channel_ids.csv

One row per detected bad channel, with channel_id and channel_id_dtype columns storing the identifier and NumPy dtype.

bad_channel_labels.csv

One row per recording channel, including good channels, with columns channel_id, label and channel_id_dtype. Labels are supplied by SpikeInterface’s detect_bad_channels().

Both files include column headers and omit the DataFrame index.
