Assess quality

Inspect RMS amplitude across channels and time to assess recording quality.

Native SpikeInterface sorting outputs can be opened in spikeinterface-gui for inspection and manual curation.

Encode and share

Define your pipeline in a YAML configuration file. For example:

Configs

np-standard-kilosort4.yaml
raw_data_quality_metrics:
  chunk_size_s: 1.0
  num_chunks: 30
  rolling_rms_window_size_s: 3.0
  quick_metrics_only: false

bad_channel_detection:
  method: 'coherence+psd'

preprocessing:
  remove_bad_channels: {}  # detected bad channels are removed, not interpolated
  phase_shift: {}  # Neuropixels only
  bandpass_filter:
    freq_min: 300.0
    freq_max: 6000.0
  common_reference:
    reference: global
    operator: median

sorting:
  sorter: kilosort4
  params:
    do_CAR: false
    highpass_cutoff: 0.1  # Low cutoff; Kilosort still applies a high-pass filter

postprocessing:
  random_spikes:
    max_spikes_per_unit: 2500
  waveforms:
    ms_before: 1.0
    ms_after: 2.0
  templates: {}
  quality_metrics:
    metric_names: all
  compute_sparsity:
    method: radius
    radius_um: 100

Flexible data loading

Load recordings with SpikeInterface, then pass them into the Python API. Use a single recording, named sessions, or recordings already split by shank.

This example runs bad-channel detection using your own YAML configuration.

import spikeinterface as si
from spikesorted import Pipeline

recording = si.load("/data/saved_recording")

Pipeline(
    recordings=recording,
    config_path="my_pipeline.yaml",
    output_path="/results/subject_01",
    stop_after_step="bad_channel_detection",
).run()

Try spikesorted

Running a standard pipeline on an existing recording session is as simple as:

installing it:

pip install spikesorted

and running:

spikesorted \
    --sessions /rawdata/sub-001/ses-001 \
    --output_path /my_awesome_project/sub-001 \
    --config /my_awesome_project/pipeline_config.yaml
